# Smart Home Control System

## 项目背景
本项目是一个用于课程展示的智能家居控制系统骨架，目标是通过统一的项目结构演示面向对象设计与常见设计模式在真实业务中的组织方式。

## 核心功能（骨架阶段）
- 提供统一的智能设备抽象与基础设备实现。
- 提供家庭-楼层-房间-设备的层级结构定义。
- 提供命令、策略、状态、观察者、装饰器、建造者等模块的接口与空实现。
- 提供操作历史模块用于后续扩展审计与回放能力。

## 设计模式说明
- **Composite（组合模式）**：组织楼层、房间与设备的树状结构。
- **Command（命令模式）**：抽象设备控制请求，支持单命令与宏命令。
- **Strategy（策略模式）**：定义不同能耗管理策略。
- **State（状态模式）**：定义系统在安防、睡眠、派对等状态下的行为。
- **Observer（观察者模式）**：让传感器变化驱动设备响应。
- **Decorator（装饰器模式）**：在不修改设备原类前提下增加附加能力。
- **Builder（建造者模式）**：分步构建复杂场景对象。
